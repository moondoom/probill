# Probill

> ⚠️ **Проект не актуален и не поддерживается.** Код старый (Python 2, Django 1.x),
> но в нём есть разные наработки — так что бери кто хош 🍻

Биллинговая система для интернет-провайдера на Django. Управление абонентами,
тарифами, доступом в сеть и сетевым оборудованием.

## Стек

- Python 2.7
- Django 1.x (+ South для миграций)
- dojango (Dojo Toolkit в админке)
- FreeBSD: ipfw, netgraph, flow-tools (netflow)

## Структура проекта

- `billing/` — ядро биллинга: абоненты, тарифы, платежи, периодические списания
- `nas/` — управление NAS (серверами доступа), генерация правил ipfw/netgraph
- `moon/` — личный кабинет абонента
- `iptv/` — модуль IPTV
- `lb/` — интеграция с LANBilling (SOAP)
- `userside/` — интеграция с ERP Userside
- `periodic/` — периодические задачи: аренда, netflow, ipfw pipe/ng_car, dhcpd, ARP
- `lib/` — сетевые утилиты
- `main/` — общие вьюхи и урлы

## Что умеет (умел)

- Учёт абонентов, тарифные планы, периодические списания и аренда
- Ограничение скорости через ipfw pipe и ng_car (netgraph)
- Сбор статистики по netflow (flow-cat, flow-stat)
- Генерация конфигов ISC DHCPd
- Приём платежей: OSMP, Visa (Газпромбанк), РИБ
- Синхронизация с LANBilling и Userside
- Личный кабинет с редиректом должников

## Установка

Скопировать `settings.conf.default` в `/etc/probill/settings.conf`
(или `/usr/local/etc/probill/settings.conf`), заполнить доступы к БД,
пути к утилитам (ipfw, flow-tools и т.д.) и запустить `manage.py` под Python 2.
